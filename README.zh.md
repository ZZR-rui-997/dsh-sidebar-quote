# dsh-sidebar-quote 使用说明

在右侧文档预览（Markdown / PDF / Office / 纯文本 / 代码）里选中一段文字，就地提问：选区会以只读引用的形式进入输入框，你的问题跟在后面。输入框旁的小鲸鱼可以把草稿改写成一份能直接执行的提示词——每一步都经过你的确认。

## 功能

### 1. 引用并提问

1. 在文档预览里选中文字，浮出「引用并提问」按钮；
2. 旁边出现小卡片，显示引用预览和来源文件名（预览能提供时）；
3. 输入问题，Enter 存入输入框（Shift+Enter 换行，Esc 取消）；
4. 引用以只读形式进入输入框，多段之间自动空行。

超过 8000 字符的选区会被截断，卡片会明确提示「超出上限的部分已截掉」，不会静默丢失。

### 1.5 框选图片

Word / PPT 里的插图转成 PDF 之后就是一整块像素，选不到"图片"这个对象。所以改成框选：

1. 预览右上角点「框选图片」；
2. 在页面上拖一个方框，圈住要改的那张图；
3. 松手后卡片打开，引用里写明「文件 + 第几页 + 横向/纵向百分比」，并把截图存到临时目录后附上路径——agent 可以直接打开这张裁剪图（也能从源 docx 里抽出内嵌原图）；
4. 框太小、或者框落在页面外/页间空隙时，会明确提示原因，不会静默失败。

### 1.6 拖文件进侧栏直接打开

从资源管理器把文件拖到右侧栏，松手就在侧栏打开（和点那里的链接走同一条通道）。只有桌面版能提供真实文件路径；浏览器版会明确提示这一点，不会瞎猜路径。

### 2. 提示词优化（小鲸鱼）

点鲸鱼后走两阶段改写：

1. **找缺口**：分析草稿缺什么（任务边界 / 背景 / 约束 / 输出形式 / 验收标准五类）。缺口会实质性改变结果时，最多问两个问题再动笔；没有值得补的缺口时直说「没改动」，不会硬改。
2. **改写**：按缺口整篇重写，允许更长或更短——没有固定模板和扩写倍率。确定性闸门会拦下编造的具体值、占位符和"只换说法"，有违规会自动跑一轮修复。
3. **预览确认**：改写结果先显示在可拖动的预览面板里（动作按钮永远在底部可见），列出「这次改了什么 / 补了哪些缺口」。你点「写入输入框」之前，输入框不会被碰；写错可点 ↩ 一键恢复。

- **等待时会告诉你进度** —— 面板会说清当前阶段（先找缺口、再改写）、已经生成多少字，
  并把刚生成的文字实时露出来，旁边是已等待秒数与「取消」；取消只是不再等，
  迟到的结果会被丢弃，不会偷偷写进输入框。`Alt+O` 可以从键盘直接开始优化。
- **预览面板的另外两个动作** —— 「复制改写」把结果复制到剪贴板；「换个写法」换一种结构
  重写同一批缺口（不是只改几个词）。每一步都仍然要你点「写入输入框」才落地。
- **引用清单** —— 插入过的引用按会话记在鲸鱼左边的「引用 N」小芯片里；点开可以看到
  引文与来源文件，点「跳回原文」会把已打开的预览滚到那句话并高亮。
- **设置页** —— 在「插件」里本插件的设置中可以关掉 `Alt+O` 快捷键、关掉生成进度、
  选择「缺信息时先问我」还是「直接写」，以及把对话里 DSH 自带的「引用文本」按钮
  一并染成主题淡色（那个按钮默认是浅灰底，白底页面上不容易看出来）。这些偏好只存在
  这台机器的这个窗口里。
- 优化后引用仍然只读：改写只动你的文字，不动引用原文。

### 3. 推荐用法

优化器**看不到会话历史**——它只能看到输入框里的草稿和引用。所以：

- 项目第一句、独立的新任务：点鲸鱼，让它补背景；
- 后续追问：直接发送，别点鲸鱼——对话历史本身就是上下文；
- 容易被误解的追问：先引用上一轮的结论，再点鲸鱼。引用是优化器唯一的上下文通道。

## 安装

npm（发布后）：

```
dsh plugin add dsh-sidebar-quote
```

或本地目录：

```
dsh plugin add <仓库路径>
```

- 框选截图写在 `DSH_HOME/sidebar-quote/crops`（默认 `~/.dsh/sidebar-quote/crops`），
  超过一周的旧文件会被清理；放系统临时目录会被清掉，而草稿还在引用那个路径。

## 模型与隐私

优化使用当前会话已选的模型，每次优化两次调用（分析 + 生成，输出上限 2048 / 8192 tokens）。发送内容只有草稿和引用；插件自身不保存任何历史。
